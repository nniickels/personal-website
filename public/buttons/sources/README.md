# Supplied site buttons

Unmodified artwork supplied by the user for wildbread.pictures,
coffeeplant.neocities.org and ribo.zone.

The button wall uses animated GIFs for Wildbread and ribo.zone, with the original
frames, frame timings and loop settings preserved. Coffeeplant remains static.
Each has a colour-matched bevel. The 82 × 25 interior is checked against the
source pixel for pixel on every frame; artwork is never resized.
First-frame SVG versions of the GIFs are also generated for reference.

Regenerate all five added buttons with `node scripts/build-linked-buttons.mjs`.
The shopping cart and apples are original integer-grid SVG pixel drawings.
