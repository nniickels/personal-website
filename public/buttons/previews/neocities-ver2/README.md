# Neocities ver2 button previews

Six static 88 × 31 SVG proposals. These are not connected to the site.

Flower imagery is adapted from the user's `neocities/ver2` artwork into a fixed 12-colour grid. Each finished SVG consists solely of integer-coordinate pixel rectangles. `comparison.png` shows a 4× nearest-neighbour enlargement and a native-size example.

Regenerate from the personal-website root with `node scripts/preview-neocities-ver2-buttons.mjs` while the sibling Neocities ver2 folder is available.
